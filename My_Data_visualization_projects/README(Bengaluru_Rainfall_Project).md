# Rainfall Analysis Project (1901–2025)

## 1. Project Overview
The Rainfall Analysis Project focuses on analyzing India's rainfall data from 1901 to 2025 using Microsoft Excel. The main objective is to understand rainfall patterns, identify yearly changes, and find the highest and lowest rainfall years through data analysis and visualization.

## 2. Tools Used
- Microsoft Excel
- Excel Formulas
- Charts and Graphs
- Excel Dashboard

## 3. Dataset Description
The dataset contains rainfall information from 1901 to 2025.

It includes:
- Year
- Monthly rainfall (January to December)
- Total annual rainfall
- El Niño information
- La Niña information

## 4. Data Cleaning and Preparation
The following steps were performed:
- Checked the dataset for missing values.
- Identified and handled missing rainfall data.
- Checked the data for accuracy.
- Unpivoted the monthly rainfall data for better analysis.
- Organized the data into a structured format.

## 5. Data Analysis
The following analysis was performed:
- Calculated average rainfall.
- Identified the year with the highest rainfall.
- Identified the year with the lowest rainfall.
- Analyzed yearly rainfall patterns.
- Compared rainfall values across different years.

## 6. Key Findings
- Highest rainfall year: 2022.
- Lowest rainfall year: 1913.
- Average annual rainfall: Approximately 960.95.

## 7. Data Visualization
Charts and graphs were created to present rainfall trends and make the data easier to understand.

An Excel dashboard was also created to display important information and analysis results in one place.

## 8. Project Objective
The main objective of this project is to improve data analysis skills, understand historical rainfall patterns, and present meaningful insights using Excel.

## 9. Conclusion
This project helped in understanding how historical rainfall data can be cleaned, analyzed, and visualized using Microsoft Excel. The dashboard provides a simple way to understand rainfall trends from 1901 to 2025.
